# ジモティー メッセージ定型（スマホのメモに貼る）

《 》は毎回埋める。3日＋3日・10〜17時・15分は仮置き。このファイルに連絡先・外部リンクを書かない。

## 1 初回返信
```
メッセージありがとうございます。ベストプライス（岡谷市の古物商）の小林です。始めたばかりの小さな店ですが、1点ずつ丁寧に対応します。
流れは、①写真を送っていただく ②24時間以内に目安額をお返しする ③ご納得いただけたら岡谷駅前など日中の公共の場所でお会いし、現物確認と本人確認のうえ確定額をお伝えする、の3つです。ご自宅には伺いません。
やりとりはこのメッセージで完結します。以後の窓口は、受け渡しの際に紙でお渡しします。
続けて写真の撮り方をご案内します。
```

## 2 写真依頼
```
写真は次の6枚をお願いします。①正面 ②背面 ③側面または底面 ④傷や汚れ（一番気になる所）⑤型番または刻印 ⑥付属品を並べて。
撮り方: 昼間の窓ぎわなど明るい場所で、無地の机や床に置き、1枚に1面。画面はライトの映り込みを避けてください。傷は隠さず写した方が、目安額と確定額の差が小さくなります。
iPhoneは追加で3枚: ⑦設定＞一般＞情報の画面（機種と容量）⑧バッテリーの最大容量の画面 ⑨ネットワーク利用制限の判定ページ（記号が見える所）。
送り終えたら「以上」と一言お願いします。
```

## 3 目安額提示
```
写真ありがとうございます。目安額は 《目安額》円 です。
根拠: フリマの直近実売が 《下限》〜《上限》円 の帯で、そこから販売手数料・送料・当店の取り分を引いています。
目安額は写真の範囲での金額で、確定額は現物を見てお伝えします。傷や動作に写真と違いがあれば下がることがあります。
この額で進めてよければ受け渡しの日時をご相談させてください。見送る場合も費用はかかりません。
買取額が合わない場合は、業者向け市場で代わりに販売するお預かり販売（手数料は全部込み20%）もあります。ご希望なら受け渡しの際にご説明します。
```

## 4 受け渡し調整
```
場所は次のどちらかでお願いしています。①岡谷駅前ロータリー ②《店舗名》の駐車場。いずれも日中（10時〜17時）のみです。
当日は、現物確認 → 本人確認書類のご提示（運転免許証など。氏名・住所・生年月日を台帳に控えます）→ 確定額のご提示 → ご納得いただけたらお支払い、の順で15分ほどです。
iPhoneは確定後にご本人の手で初期化していただきます。
都合のよい日時を2つほど挙げてください。当日の連絡もこのメッセージで行います。
```

## 5 断り（3型）

a 無料引取・処分希望
```
ご相談ありがとうございます。当店は買取のみで、無料での引き取りや処分のお手伝いは行っていません（廃棄物の収集には別の許可が要るためです）。お手数ですが市の粗大ごみ受付や家電リサイクルの窓口をご利用ください。売れる見込みのある品物があれば、改めてお声がけください。
```

b 自宅希望
```
ご自宅への訪問は行っていません。駅前など公共の場所でお会いする形でお願いしています。ご都合が合えばご相談ください。
```

c 動作不明の家電
```
冷蔵庫・洗濯機・テレビ・エアコンは、動作が確認できる物に限ってお受けしています。今回は見送らせてください。
```

## 画像不備の二段（再撮影1回 → 保留3日 → 最終クローズ）

第1段 再撮影依頼（不備に気づいた直後・1回のみ）
```
写真ありがとうございます。目安額を出すのに、次の写真がもう少し必要です。
・《番号と理由。例: ⑤型番が読めません。設定＞一般＞情報の画面をそのまま》
・《例: ④傷の写真がぶれています。明るい場所でピントを合わせて》
お手数ですが追加をお願いします。《日付》まで（3日ほど）お待ちします。
```

第2段 保留通知（3日経過・追加なし）
```
先日の写真の件、いったん保留にさせてください。追加の写真が届けば、いつでも再開して目安額をお返しします。《日付》まで（あと3日）お待ちして、その後は一度この相談を終了します。
```

最終クローズ（さらに3日経過）
```
本日で一度この相談を終了します。写真が揃った時点で、同じ投稿からまたメッセージをいただければ最初から対応します。ご相談ありがとうございました。
```

運用: クローズ後は追わない。投稿は消さない。台帳に「画像不備クローズ」として1件数える。
