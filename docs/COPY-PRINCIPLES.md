# LP コピー改善の原則

## 前提

- 対象は `index.html` の文言だけ。構造、class、id、data 属性、画像、CSS、JS は変えない。
- 数字と条件は `config.js` を正本とし、既存の約束を増減しない。
- 実績がないことを隠さない。事実を強く、短く、具体的に伝える。
- 3冊の本文は直接引用せず、LPで使える原則に要約した。

## 採用する原則

| # | 原則（出典） | LPのどこに | どう変えるか |
|---|---|---|---|
| 1 | 小さな行動から始めると、次へ進みやすい（『シュガーマンのマーケティング30の法則』一貫性・巻き込み） | hero / flow / contact | 最初の行動を「品物を送る」ではなく「写真6枚を送る」にする。目安額を見てから発送を決められる順番を繰り返す。 |
| 2 | 弱点を先に出すと、読む人の警戒が下がる（同書・欠点の先出し） | hero の honest / weak | 「始めたばかり」「実績の数字はまだない」「通常2〜3週間」「送料は元払い」を短く先に出す。 |
| 3 | 具体性は信用の土台になる（同書・具体性） | license / flow / fee / faq | 許可主体、写真6枚、5つの流れ、24時間以内、手数料、3営業日を、関係する場所の近くに置く。 |
| 4 | 選択肢を減らすと、決めやすくなる（同書・単純さ） | fee / flow | 手数料は全部込みの1つとして見せる。流れは5段階に分け、各カードで伝える動作を1つに絞る。 |
| 5 | 読む人が使う場面を想像できる言葉にする（同書・巻き込み） | hero / flow | 会社側の説明より先に、「写真を送る」「目安額を見る」「送るか決める」という利用者の動作を書く。 |
| 6 | 自分の言いたいことではなく、相手の得から組み立てる（『伝え方が9割』お願いの3ステップ） | hero / license / fee | 「業者市場で売れる」「送る前に目安が分かる」「あとから別の手数料を引かない」を主語の近くに置く。 |
| 7 | 選ぶ自由を残すと、頼みごとの負担が軽くなる（同書・選択の自由） | hero / flow / faq | 目安額を見たあとに、発送するか見送るかを選べることを明記する。キャンセルできる時点も分けて書く。 |
| 8 | 長い説明は、短い出だしで要点を先に渡す（同書・長文の技術） | 各見出し / lead / faq | 見出しと最初の1文だけで結論が分かるようにする。1文に複数の説明を詰めず、短く切る。 |
| 9 | 数字は内容の輪郭をはっきりさせる（『伝え方が9割 2』ナンバー法） | hero / flow / fee | 新しい数字は作らず、既存の「6枚」「5つ」「24時間以内」「20%」を、判断する場所で見せる。 |
| 10 | 手順を物語の順番で見せると、自分の体験として読める（同書・実践ストーリー） | flow | 「まず」「目安額に納得したら」「到着した日」「落札・入金後」の順で、利用中の場面が続くようにする。 |

## Before / After

| 場所 | Before | After |
|---|---|---|
| hero 見出し | 送るだけ。業者オークションで、あなたの代わりに売ります。 | 写真を送るだけ。業者だけの市場で、あなたの代わりに売ります。 |
| hero lead | 写真を送ると24時間以内に目安額を返事。納得したら宅配便で送る。 | 写真6枚で24時間以内に目安額を返事。金額を見てから、品物を送るか決められる。見送れば0円。 |
| hero チップ | 法人運営／全部込み20%／明細／開封動画 | 法人がお預かり／売れたら全部込み20%／明細／到着した日の開封動画 |
| hero 正直表示 | 先に正直に書きます。サービスは始まったばかりで、実績の数字はまだ出せません。 | 始めたばかりです。実績の数字はまだ出せません。明細と出品先を毎回知らせます。 |
| license 見出し | 許可があるから、できること | 古物商許可のある法人がお預かりします |
| license 説明 | 許可の説明、業者市場、委託、本人確認、会社運営を長い文で説明 | 許可主体、業者市場、売れてからの振込、本人確認、明細の順に短く説明 |
| flow 冒頭 | 流れは5つ。対面はありません。 | 写真6枚から、5つの流れ。対面はありません。 |
| flow カード | 各カードに条件と説明が長く連なる | 1カード1動作に絞り、目安額を見てから発送を決める順番を明確化 |
| fee 見出し | 手数料は、ひとつの数字だけ。 | 引かれる手数料は、ひとつだけ。 |
| fee lead | 出品料・成約料・落札料は全部この中。あとから引かれるものはない。 | 出品料・成約料・落札料も含む。あとから別の手数料は引かない。 |
| fee 継続・紹介 | 2回目17%、紹介があれば最低14%まで下がる。 | 2回目は17%。紹介がある場合の下限は14%。 |
| weak 見出し | 向いていない人 | 合わない方も、先にお伝えします |
| weak 早さ | 今日中に現金が欲しい方。即金の買取ではない。 | すぐに現金が必要な方。発送から通常2〜3週間かかるため、早さを優先する方には合わない。 |
| weak 自分で売れる方 | 個人間フリマの方が高く売れることはある。 | 個人間フリマで売る方が、手元に残る額が多くなる可能性がある。 |
| faq 落札額 | 査定額は誰が決めるのですか？ | 落札額は誰が決めますか？ 競りで決まり、返事は目安で確定額ではない。 |
| faq 最低希望額 | 目安額より低い落札になったら？ | 最低希望額を下回りそうなら？ 下回る場合は売らず、無料で返送する。 |
| faq 入金 | 落札確定、業者入金、3営業日以内の振込を1文で説明 | お金の流れを矢印で示し、通常2〜3週間と予定日の伝え方を短文で説明 |
| faq 費用 | 手数料以外はかからない。発送時の送料だけ負担。 | 発送時の送料と、出品前キャンセル時の返送料を明記。目安額を見て見送る場合は0円。 |
| contact | まずは写真を送ってください。 | 写真6枚で、目安額を確認できます。 |
