## 動画1: LINE用「写真の撮り方」説明動画（縦型・約50秒）

**目的**: LINEに来た人の「どう撮ればいいか分からない」を消し、発送に進めてもらう(CVR: 依頼→発送を上げる)。拡散用ではない。

**画面比**: 9:16(縦)。**素材**: assets/steps/step1〜5.webp と、実機で品物を撮る手元(あれば)。

| 4-12 | step1.webp(手元で撮る) | 「1枚目 正面全体。品物が全部入るように」 |
| 12-18 | step画像/イメージ | 「2枚目 背面全体。シール跡や改造が分かります」 |
| 18-24 | 同上 | 「3枚目 側面と底面。角の打痕や歪み」 |

**要点**: 「傷を隠さないほうが得」を必ず入れる(LPと同じ方針)。金額は出さない。最後は「送るだけ」で終える。

## 動画2: 集客用「残債でも売れるか、判定の見分け方」（縦型・約60秒）

**目的**: 「分割が残っていて売れないと思っている人」に届き、LINEへ。集客(到達→追加)。X・Instagramリール・LINE・(YouTubeショートはリバースハック)兼用。
**画面比**: 9:16。**素材**: assets/content/x-zandebug.png(詰まった画面・訂正済み)、判定サイトの画面録画(IMEIは映さない・記号だけ)、greeting-thumb.png。
**フック**: 失敗・恐怖から。自慢話にしない。

| 秒 | 画面 | 字幕/ナレーション |
|---|---|---|
| 0-6 | x-zandebug.png(手が止まった画面) | 「iPhoneを売ろうとして、最後で手が止まりました」 |
| 6-14 | チェック欄をズーム | 「『ネットワーク利用制限がないことを確認しました』。分割が残っている自分は、正直にチェックできなかった」 |
| 14-22 | 暗転→文字 | 「嘘は書けない。でも調べたら、止まる必要はありませんでした」 |
| 22-34 | 説明図(キャリア分割 vs Apple直販) | 「制限がかかるのはキャリアの分割で買った端末。Apple直販をカードやPaidyで払っている端末は、判定は通常『−(対象外)』」 |
| 34-44 | 判定サイトの画面録画(記号だけ) | 「IMEIを4キャリアの確認ページに入れるだけ。○か−なら、正直にチェックして売れます」 |
| 44-52 | 記号の意味を文字で | 「○=制限なし ／ −=対象外 ／ △=分割支払い中 ／ ×=制限あり」 |
| 52-60 | greeting-thumb.png →「判定」 | 「自分のがどれか分からない方は、LINEで『判定』と送ってください。見分け方から案内します」 |

**要点**: 残債額・金額を映さない。赤ロム混同を避ける(「払いが滞ると使えなくなる」は言わない)。判定サイトの画面はIMEI欄を隠すかぼかす。最後のCTAは「判定」1種類。

## 作り方メモ（撮影・編集）
- スマホの画面録画で判定サイトを撮るときは、IMEI入力欄を指で隠すか、後で黒塗り。記号の結果だけ見せる。
- 字幕は大きめ・中央〜下1/3。音なし再生に耐えるよう、ナレーションと同じ内容を字幕に出す。
- 60秒は X/Instagram/YouTubeショートの上限に収まる。LINEは尺の制限が緩いが、50〜60秒で揃える。
- 1本目(撮り方)を先に作ると、LINEに来た人の発送率が上がる。2本目(判定)は集客。まず1本目を勧める。
- iPhone売却の「一部始終」動画は別物。売れて発送・入金が済んでから、金額を伏せて作る(単発・リバースハック)。

## 動画3: Instagramリール「残債でも売れる」（縦型・約18秒・6枚スライド版）

**目的**: Instagramはリール(動画)を優先表示するので、フォロワー0でも見つけてもらいやすい。既存のカルーセル6枚(assets/content/ig/01〜06.png)をそのまま動画化する。
**作り方**: CapCut(無料アプリ)か ffmpeg で、6枚を順に表示。字幕は画像に入っているので追加不要。BGMは静かなもの。
**画面比**: 9:16(1080×1920)。素材は既存の assets/content/ig/01〜06.png(正方形なので上下に余白を付けて縦に配置、または中央に大きく)。

| 秒 | 表示 | 動き/演出 |
|---|---|---|
| 0.0-3.5 | 01.png（手が止まった話） | 最初の3.5秒で掴む。フェードインなしで即表示 |
| 3.5-6.0 | 02.png（分割＝売れないではなかった） | 左からスライドイン |
| 6.0-9.0 | 03.png（Apple直販+Paidyは−） | 同上 |
| 9.0-11.5 | 04.png（IMEIで確かめる） | 同上 |
| 11.5-14.5 | 05.png（○−△×の意味） | 記号が出る所で0.3秒ズーム |
| 14.5-18.0 | 06.png（LINEで「判定」） | 最後は少し長めに。CTAを読ませる |

**守ること**: 金額・実績を入れない(画像に既に入っていない)。BGMは著作権フリーのもの(CapCutの標準音源はOK)。字幕はそのまま。

**CapCultでの作り方（スマホ・10分）**
1. CapCut を開く → 新しいプロジェクト → 6枚(01〜06)を順に選ぶ。
2. 各クリップの長さを上の表の秒数に合わせる(だいたいでよい)。
3. 比率を 9:16 に設定。正方形画像は上下に余白が出るので、背景を紺(#0A2138)で塗るか、少し拡大して埋める。
4. BGMを1つ足す(静かなもの)。
5. 書き出し → Instagram にリールとして投稿。キャプションはカルーセルと同じでよい。

**ffmpegでの作り方（PC・私が代われる）**
- 6枚を9:16のキャンバス(1080×1920・背景紺)に中央配置し、上の秒数で連結してmp4を書き出す。BGMなし。あとでCapCutでBGMを足せる。
