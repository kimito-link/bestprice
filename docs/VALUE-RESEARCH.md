# 価値をもっと出せるか（調査メモ・2026-09-08）

> 問い: 買取代行の入口から、無料の診断レポートなどで「もっと価値が出せるか」。
> 方法: Web検索（同型サービス・AI査定・法人在庫・片付け業者）＋自社リポの棚卸し（Explore agent）。
> 数字は検索で確認できた範囲。網羅ではない。「未確認」は未確認と書く。

## 1. 市場の事実（検索で確認したもの）

### 1-1. 「写真→AIが相場を返す」はもう当たり前になっている
| 事例 | 何ができる | 出典 |
|---|---|---|
| Yahoo!フリマ「らくらくAI査定」 | LINE公式に写真1枚→AIが相場価格・平均売り切れ時間を返す。アプリ内でも可 | lycorp.co.jp プレスリリース（2025〜2026） |
| HOW MUCH（アプリ） | 撮るだけで持ち物の価値をAI評価、毎日更新の「モノの資産管理」 | App Store |
| プレミアバリュー（時計） | 生成AIが30秒で買取価格を回答。写真も個人情報も不要 | PR TIMES 2026-03-06 |
| 大黒屋 | 写真1枚から数秒で商品属性判定（LINE×AI） | daikokuyajp.com |

→ **「AIで目安額が速い」だけでは差別化にならない。** 目安額は「あって当然」。価値は別の所に置く。

### 1-2. 同型（預かって業者オークションで売る）は数社・高額品限定
retro（返金率70〜90%・想定2万円以下は買取のみ）／シグマ（5万円以下は買取のみ）／リユース相談本舗／ブルーム／RECLOスマート出品。
岐阜の朝日堂は「古物市場出品代行 手数料20%」で昭和レトロ・骨董を扱う（レトロハンター）。
→ **低額品・多品目・地方は空いている**（既出の結論と同じ）。

### 1-3. 業者オークションに出品しているのは「ブランド買取店・遺品整理業者・片付け業者・訪問買取業者」
ウルマガ（brand-jds.jp）の記述。片付け・遺品整理の側は全国907業者が「みんなの遺品整理」に掲載（協会認定）。
→ 個人だけでなく、**業者を「出品代行の顧客」にする余地**がある（仮説・要ヒアリング。小規模業者がオークション会員になっていない／出品の手間を嫌う、が前提）。

### 1-4. 法人の在庫・備品処分は大手が「買取」で押さえている
トレファク法人在庫買取／高く売れるドットコム（法人・出張）／セカンドストリート法人買取／クローズランド／エコロジーモール。
→ 大手は**買い取る＝資金が要る**。閉店・移転する**地元の小さな店**に対して「委託で、処分診断から」は空いている（仮説）。

### 1-5. 片付け・生前整理は「LINEで30秒見積り」＋買取充当が定番
Katazukedou（LINEで30秒お見積り、買取金額を作業費に充当）／みんなの遺品整理（無料で業者選び相談）。
→ 「無料の見積り・診断を入口にしてLINEへ」はこの業界でも型になっている。うちの得意型（診断→LINE→課金）と同じ。

### 1-6. 地元（諏訪・岡谷・塩尻）の競合
セカンドストリート諏訪インター店／出張買取MAX（長野全域）／リユース相談本舗（塩尻ページあり）／おいくら掲載店。
→ 全部「買取」。委託型は地元に見当たらない（検索範囲）。

## 2. 訴求の追加（2026-09-08 ユーザー指摘）: 「売る」以外にもお金が入る道を渡す

> ユーザーの言葉（要旨）: 買取に来る人は「お金が欲しい」人。無料の診断を知り合いのお店に見せて診断してもらい、
> その店が依頼につながれば紹介した人にお金が入る、という訴求もいい。

**型:** 買取の窓口に来た人 ＝ 見込みの紹介者。
1. 品物を送ってくれた人に、振込明細と一緒に「紹介リンク」を渡す（手数料−3ptの紹介特典は既存設計。ここに**現金の紹介料**を足す）
2. 紹介リンク先は、①買取代行（知り合いが送れば紹介料）②無料の診断（知り合いのお店の口コミ・サイト・AIの診断）
3. 診断を受けたお店が有料の相談・月額に進んだら、紹介した人に報酬（他事業の `?ref` 継続報酬20%の実装をそのまま使う）

**なぜ効くか:** 「自分の物を売る」は1回で終わるが、「知り合いを紹介して稼ぐ」は続く（LTV）。
お金が欲しい人ほど紹介の動機が強く、しかも紹介先は「診断が無料」なので相手に負担がない（CVR）。

**実装の前提（ここを飛ばすと守れない約束になる）:**
- 紹介報酬の**支払いが自動化されるまで、紹介者は少数（10人以内）で手動払い**に限る。
  [[referral-video-blocked-on-payout-automation]]（報酬の支払い自動化前は紹介プログラムの動画を作らない）と
  [[payout-automation-design]]（着手は受取人10人 or 月50件から）に従う。
- 報酬の条件・締め日・支払方法を**先に文章で公開**する（後出しは信頼を壊す）。
- 診断の紹介先は「お店・会社」なので、買取の客層（個人）から店主・経営者だけを拾う導線が要る
  （振込明細の1行「お店をやっている知り合いはいますか？」で十分。作り込まない）。

**まだ確認していないこと:** 紹介料の額（買取: 落札額の何%か固定額か／診断: 既存の20%をそのまま使うか）、
特定商取引法・景表法上の表現（「誰でも稼げる」は書かない。実績が出るまで金額の断定をしない）。

判断軸: 新しく買う道具0円／使うのは§3の器だけ／数えるのは**発送件数と紹介経由の依頼数**／1案=1週間の実験。

| 優先 | 案 | 誰に・何を | 使う器 | CVR/LTVへの効き | 撤退線 |
|---|---|---|---|---|---|
| **1** | **売り先くらべレポート**（品物1点ごと） | 「業者の競り（うち）／自分でフリマ／近くの買取店」の3つで、手取り・日数・手間を横に並べる。**自分で出した方が得なら、そう書く** | レポートURL＋OG画像＋禁句CI | AI目安額が当たり前になった今、**正直な比較**が唯一の差になる（CVR）。モニター10件の成果物にもなる | 2週間で「送る」に至った率が写真の2割未満なら文面を替える |
| **2** | **紹介で稼ぐ**（§2） | 送ってくれた人に紹介リンク。①知り合いが送る→紹介料 ②知り合いのお店が無料診断→有料に進めば報酬 | affiliateRef＋go.astro＋pincersの文言設計＋既存の?ref継続報酬 | 「売る」は1回、「紹介」は続く（LTV）。診断側の新規客も増える | 紹介者10人までは手動払い。支払い自動化前に動画・広告で募集しない |
| **3** | **眠り資産レポート**（家1軒） | 家の中の写真をまとめて送る→「送る価値あり／送料負け／捨てないで」の一覧と目安合計、どこで売るか | レポートURL＋しおり（半年後にもう一度）＋LINE返信ルール | 1人あたりの点数が増える（客単価）。しおりで再訪（LTV） | 目安合計に対する実落札が7割を切ったら目安の出し方を直す |

## 5. 上村さんの「レビチカ（Levitica）」との相性（2026-09-08・資料2本を読了）

**レビチカとは（資料の要旨）:** 「地下に眠る良いお店を発掘する」。Googleマップを店の公式フロントページにし、
メニュー・今日のキャンペーン・LINE予約・求人を1ページに。MEOツールではなく「応援される店を増やす活動」。
主ターゲット＝地域密着の個人店（美容室・カフェ・飲食・サロン・整体・小規模クリニック、1〜2店舗）。
オーナー像＝Instagramは頑張っているがマップまで手が回らない／MEO営業に疲れている／
**マーケ用語（SEO・MEO・CPA）は響かず、「応援・紹介・地域・想い・ファン」の言葉に反応する**。

### 5-1. 重なっている所（＝そのまま組める）
| レビチカ側 | うち側（実在する資産） | 組み方 |
|---|---|---|
| 相手＝地元の個人店オーナー | 診断の相手＝同じ（口コミチェック.jp・WEB健康診断・AI健康診断）／買取代行の横展開先＝同じ | **入口を共有**: 無料の口コミ診断（星・件数・選ばれやすさ・競合比較）を見せて、「応援される店」への最初の一歩にする |
| 「応援される店」を増やす | キミトリンクの理念そのもの（クリエイター応援・応援動画・流れ星）。`ouenmovie`＝縦型応援動画の量産パイプライン（実測: 応援動画は自社動画の6.4倍見られる） | **店の応援動画**を作って店のマップページ・SNSに置く。レビチカの「コンテンツが届きやすい層」に刺さる |
| 「LINEで予約」「LINE誘導」 | `line-bot`（LINE Harness／AI社員・OSS） | 店ごとのLINE受付をうちの部品で用意 |
| 「気持ちの言葉」で作る | web-ios-android の「小学生でもわかる言葉」ルール／キャラで親しみやすく | 文章の作法が同じ。同じ人が書ける |
| 店舗ページを生成・アプリ化 | `web-ios-android`（LP/iOS/Android/Chromeの自動提出）、`templates/web/site-chrome/` | レビチカのアプリ化・店舗ページ量産の土台 |
| 営業対象＝Googleマップ上の全店舗 | `Target-List-maker`（法人リスト自動収集・有料$0.05〜0.15/件） | 地域を絞った店舗リストの初期作成 |
| 「評判改善の意識UP」 | `removal/review-tool.html`（来店客がタップで本音の口コミを書ける補助・API費用0） | 店に置く「口コミを書きやすくする道具」として提供 |

### 5-2. 買取代行との直接の接点（お金が動く3本）
1. **店→買取代行**: レビチカに載った店の「在庫・備品の処分」を委託で受ける（§4 案4）。閉店・改装・季節替えのたびに出る。
2. **店→紹介料**: 店のレジ横に「いらない物、送るだけ」のQR（LPは既にある）。お客さんが送れば店に紹介料。**店主も「お金が欲しい人」**。
3. **買取の客→店**: 品物を送ってくれた人（地元）に、レビチカの店を「応援」として紹介。§2の「紹介で稼ぐ」の紹介先に**地元の店**が加わる＝応援と紹介料が同じ導線に乗る。

### 5-3. ★注意: ピンサーズ（有償クチコミ）はレビチカの理念と正面衝突する
ピンサーズ＝Googleクチコミ投稿でお小遣い（PayPay払い・30日安定表示で確定・ランク制）。
- 2023年10月施行の**ステマ規制（景表法5条3号）**では、対価を受けた口コミを広告と分からない形で出すと**広告主（店）が処分対象**。Googleのポリシーも対価付きレビューを禁止。
- レビチカは「広告費ではなく実際の評判で見つかる世界」が理念。**買われた口コミが混ざった瞬間に理念が崩れ、店が処分リスクを負う**。
- **組むなら形を変える**: 「口コミを書く人にお金」ではなく、①来店客が本音を書きやすくする道具（review-tool）②書いた口コミに店が「ありがとう」を返す運用③応援動画・紹介で店の露出を増やす、の3つに置き換える。ピンサーズの**成果報酬・仮確定30日・ランク制の仕組み**は、口コミではなく**買取代行と診断の紹介報酬**（§2）に転用する。
- 未確認: ピンサーズの現行運用がどこまで進んでいるか（LPはβ、`pincers/lib/content.ts` の設計のみ確認）。

### 5-4. 最初の一手（上村さんに提案できる形）
- **「口コミ診断 → 応援動画 → 買取QR」の3点セットを、地元の個人店3軒で試す**（諏訪・岡谷）。費用0円。
  数えるのは「診断を受けた店の数」「動画を置いた店の来店LINE登録」「店経由の買取の発送件数」。
- レビチカ側は店の「公式フロントページ」、うち側は「入口（診断）」「中身（動画・LINE）」「出口（買取・紹介料）」。役割が重ならない。

### 5-5. 「お店の支援ページを作ります」を提供物にする（2026-09-08 ユーザー提示）
ユーザーが共有した実物: `clinic-review-demo.jsx`（Claude公開アーティファクト。矯正歯科向け・7問・タップのみ・約1分・
来院区分／待ち時間／先生の説明／受付／清潔感／気になった点／また来たいか → 文章を組み立て → コピー → Googleマップの投稿画面へ）。
`removal/review-tool.html` と同じ型で、**店ごとに `STORE` と `QUESTIONS` を差し替えるだけ**で量産できる。外部API費用0。

**なぜレビチカと両立するか:** 対価を払わない／来店した本人が自分の言葉を選ぶ／「改善してほしい」「かなり待った」等の
**悪い選択肢を消していない**（良い口コミだけ通す「レビューゲーティング」ではない）。だからステマ規制にもGoogleのポリシーにも触れない。
★守ること: 割引・特典と引き換えにしない／否定的な選択肢を減らさない／「※内容はご自身で自由に変更できます」を残す。

**1店1ページの中身（応援ページ）:**
1. 口コミ作成補助（上のデモ型・店の色と質問に差し替え）
2. 店のLINEへの導線（`line-bot` の部品）
3. 「いらない物、送るだけ」の買取QR（店に紹介料）
4. 店の応援動画（`ouenmovie` 型）の埋め込み
→ レビチカの「Googleマップ公式ページ」から、この応援ページへリンクする。うちが作る側、レビチカが載せる側。

**値段の考え方（仮）:** 初期は無料（診断→応援ページまでを無料の入口にして、店のLINE・買取・月額の監視で回収）。
