# 買取代行（お預かり販売）システム設計図 — best-price

作成: 2026-09-07 ／ 状態: 設計完了・LP実装済み・LINE公式は未着手（ユーザー指示で後回し）

> 前提: 法人登記あり・古物商許可あり・**資金ゼロ**・査定スキルなし・対面ゼロ。
> 起点は長野県 諏訪・岡谷・塩尻・下諏訪。うまくいけば全国展開。
> 目標: CVR（写真送付→発送に至る率）と LTV（同じ人が2回目以降も送ってくる）の最大化。

## 0. 最初に決めた設計判断（蒸し返さない）

| # | 判断 | 理由 |
|---|---|---|
| 1 | **「買取」ではなく「お預かり販売（委託）」を基本レーンにする** | 資金ゼロで買取をすると、お客様への支払いが業者からの入金より先に来て詰む。委託なら**入金を受けてから払う**ので資金ゼロで回る。「売却の委託を受ける」も古物営業なので許可の範囲内。 |
| 2 | **即金は約束しない。代わりに「速さ」を3つに分解して約束する** | 目安額の返信24h以内／入金予定日を確定日で伝える／最低希望額を下回れば無料返送。即金を偽ると口コミで一発で死ぬ。 |
| 3 | **手数料はオークション実費込みの「全部込み20%」** | 成約料・落札料・月額を別建てにすると計算できず離脱する。全部込みの1つの数字だけ見せる。 |
| 4 | **貴金属（地金）はオークションに出さず地金業者へ** | 地金は相場が公開されていて、地金業者の当日相場買取の方が高く速い。品目ごとに出口を変える。 |
| 5 | **初期の販売先は固定費0円のものだけ（タイムレス・地元卸の相見積もり・地金業者）** | 固定費は極端に嫌う。オークネット（月3,800円）は「発送が月5件を超えた月」から。エコリング（入会3万＋年2万）は月商が立ってから。ASMMはスマホが月10台を超えてから。 |
| 6 | **LINE公式は後回し。LPと写真テンプレを先に出す** | ユーザー指示（2026-09-07）。LPは `config.js` の LINE URL を1か所入れるだけで接続できる構造。 |
| 7 | **www は作らない・ドメインは1つ** | github/CLAUDE.md の方針。`domain-connect.mjs` で A レコードだけ。 |
| 8 | **「最初の10件モニター（手数料15%）」をLPに置き、需要を財布で測る** | 「欲しい」は半分嘘。品物を実際に送る＝財布を開く行動だけを需要の証拠と数える。モニターは明細と感想を公開させてもらう対価で、割引の理由が立つ。 |
| 9 | **撤退ラインを先に決める** | 30日で発送0件→集客文面を替えて次の30日。60日で発送3件未満→撤退（愛着で続けない）。1実験の賭け金は「時間1週間・現金0円」。 |

### 0-2. 臆病者の原則（2026-09-07 ユーザー共有のマーケティング指針を適用）
- **需要は「欲しい」ではなく「財布」で確認する。** このLPは商品ではなく「言葉だけの商品」であり、最初のテストそのもの。計測する数字は **発送件数**（財布を開く行動）。友だち追加数・写真の数は参考値で、証拠ではない。
- **売れたものだけ商品化する。** 初期は全品目を受け付け、30日後に**実際に送られてきた品目**へLPと集客文面を寄せる。社長の予想（スマホが多いはず）で絞らない。
- **証拠が増えるたびに賭け金を増やす。** 固定費0円の出口だけ → 発送月5件でオークネット月額 → 月商が立ってからエコリング → 手元資金30万で買取（即金）レーン。順番を飛ばさない。
- **小さく失敗できる賭けしかしない。** 1実験＝「媒体×文面」を1週間。資金ゼロなので賭け金は時間。10回外しても死なない（10週間）。
- **固定費を極端に嫌う。** 月額課金・事務所・在庫・広告費は、発送件数という証拠が出るまで1円も払わない。
- **撤退ラインは先に書く**（判断#9）。ラインに達したら愛着に関係なくやめる。

## 1. 全体フロー図（個人 → 私 → 業者）

```
【個人（売りたい人）】
   │ ①写真を送る（LINE。LINE稼働までは LP の「メールで送る」ボタン）
   ▼
【私（法人・古物商）】
   │ ②目安額レンジを返す（24h以内・営業時間内）
   │    ├ 根拠: 直近の業者オークション落札相場を目視で調べる
   │    └ 断定しない。「落札目安 ○万〜○万」「最低希望額をご指定ください」
   │ ③お客様が発送（元払い・追跡番号あり・本人確認書類の写しを同梱）
   │    └ 送り先は届出済み営業所住所。到着前に受取場所をコンビニに変更
   ▼
【コンビニ受け取り → 検品 → 台帳記帳】
   │ ④到着当日: 開封動画を撮る／写真と現物を照合／古物台帳に記帳
   │    ├ 写真査定と食い違いがあれば「目安額を下げるか・無料返送か」を先に選んでもらう
   │    └ 本人確認（非対面の法定方法）完了を確認してから次へ
   ▼
【業者（BtoBオークション／卸）】
   │ ⑤品目ごとの出口へ
   │    ├ ブランド・時計・ジュエリー → タイムレス（0円） / オークネット
   │    ├ スマホ・タブレット      → オークネット → 台数が増えたら ASMM
   │    ├ カメラ・楽器・ゲーム・家電 → 地元卸・業者買取に相見積もり（3社）
   │    └ 貴金属（地金）           → 地金買取業者の当日相場（オークション不使用）
   │ ⑥落札・成約 → 業者から入金
   ▼
【私 → 個人】
   │ ⑦入金確認後 3営業日以内に振込（落札額 − 全部込み20%）
   │    └ 明細を必ず送る: 落札額／手数料／振込額／出品先の種別
   │ ⑧振込完了メッセージの中で次回特典（手数料 −3pt）を案内
   ▼
【再来店（LTV）】
```

**お金の流れ（資金ゼロで回る理由）**
- 私が現金を出す瞬間は「返送料（最低希望額を下回った時だけ）」だけ。オークネット月額 3,800円は発送が月5件を超えてから（固定費ゼロで始める）。
- 落札 → 業者入金 → お客様へ振込、の順なので立て替えが発生しない。
- 送料はお客様の元払い。落札額 5 万円以上なら送料分として 1,000 円を振込時に上乗せ（CVR用・原資は手数料から）。

### 2-1. CVRを高める導線（友だち追加 → 写真送付 → 発送）

```
友だち追加
 └ あいさつメッセージ（即時・自動）
 └ リッチメニュー（3分割）: ① 写真で査定  ② 撮り方ガイド  ③ 手数料と流れ
写真が届く
 └ 自動返信（即時）: 「受け取りました。営業時間内に順番にお返事します（目安 ○時まで）」

 └ 「送る」と決めた人 → 発送ガイド
```

**あいさつメッセージ（確定文面）**

### 2-2. LTVを高める施策（再来店・セグメント・特典）

| 施策 | 内容 | 発火タイミング |
|---|---|---|
| 次回特典 | 2回目以降は手数料 −3pt（17%）。上限は 14%（紹介と併用可） | 振込完了メッセージの末尾に必ず入れる |
| 紹介特典 | 紹介した人・された人の両方が次回 −3pt | 振込完了の1週間後に1通 |
| 「家に眠っている物」リスト | 品目チェックリスト画像を送り「該当ありますか？」 | 振込完了の2週間後 |
| 相場アラート | 「あなたが送った品目の相場が上がっています」（手動でよい） | 該当時のみ |
| 大会前告知 | 「次回ブランド大会は○日。○日までに届けば間に合います」 | 大会の10日前 |

**セグメント（LINEのタグで管理・手動運用でOK）**
- `写真だけ`（送ってきていない）／`成約1回`／`成約2回以上`／`紹介元`
- `品目: スマホ／ブランド／時計／カメラ／楽器／ゲーム／家電／貴金属`
- `エリア: 諏訪圏／長野県内／県外`

配信ルール: 一斉配信は月1回まで。それ以外は上のトリガー配信だけ。**送りすぎがブロック＝LTVゼロを生む。**

## 3. 写真査定のテンプレート

### 3-1. 全品共通（6枚）
| # | 写真 | 確認したいこと |
|---|---|---|
| 1 | 正面全体 | 品目の特定・全体の状態 |
| 2 | 背面全体 | 傷・シール跡・改造の有無 |
| 3 | 側面・底面 | 角の打痕・液漏れ・歪み |
| 4 | 傷・汚れのアップ | 減額要因を先に見て「到着後の減額」を減らす（CVRの肝） |
| 5 | 型番・シリアル・刻印 | 相場検索のキー・真贋の一次確認 |
| 6 | 付属品を全部並べる | 箱・保証書・ケーブル・替えベルト等で相場が大きく動く |

### 3-2. 品目別の追加写真・確認項目
| 品目 | 追加写真 | 確認質問（返信で聞く） |
|---|---|---|
| スマホ・タブレット | 電源ON画面／設定→バッテリー最大容量／IMEI画面 | キャリア・SIMロック・ネットワーク利用制限（△×は受付不可）・初期化とアクティベーションロック解除 |
| ブランドバッグ・財布 | 内側全体／ロゴ刻印／金具・ファスナー／角スレ | 購入店・購入時期・保証書やギャランティカードの有無 |
| 時計 | 文字盤アップ／裏蓋刻印／ブレスのコマ／保証書 | 稼働の有無・オーバーホール歴・純正パーツかどうか |
| ジュエリー・貴金属 | 刻印（K18/Pt900等）／石のアップ／重さ（キッチンスケール可） | 鑑定書・鑑別書の有無。地金は重さが値段。 |
| カメラ・レンズ | マウント面／レンズ内を光にかざした写真／液晶／シャッター回数（分かれば） | 動作・カビ・クモリ・バルサム切れの有無 |
| 楽器 | 全体表裏／ヘッド・ネック／ブリッジ／電装部／ケース | 弦交換・修理歴・ネック反りの自覚 |
| ゲーム機 | 本体／コントローラー／端子部／電源ON画面 | 初期化済みか・本体のみか・限定モデルか |
| 家電・オーディオ | 型番シール／端子／電源ON／リモコン等 | 製造年（型番シールにある）・動作の自覚症状 |

### 3-3. 受付しないもの（LPにも明記）
- ネットワーク利用制限「×」「△」のスマホ、初期化・ロック解除ができないスマホ
- 真贋が確認できないブランド品（保証書なし＋刻印不鮮明の組み合わせ）
- 大型家電（冷蔵庫・洗濯機等・宅配便で送れない物）
- 動作しない楽器・カメラのうち目安額 5,000 円未満のもの（送料負けする）

## 4. 業者への卸し方

### 4-1. 販売先の使い分け（ユーザー提示条件を基に整理。入会前に公式の最新料金で再確認）
| 出口 | 向く品目 | 初期費用 | 使う順番 |
|---|---|---|---|
| タイムレスオークション | ブランド・時計・ジュエリー | 入会・年会費 0円 | **最初に入会** |
| オークネット ブランドオークション | ブランド全般・スマホも | 入会0円／月額3,800円〜／成約3〜5%＋落札4〜6% | **発送が月5件を超えた月から**（それまで固定費は払わない） |
| ASMM | スマホ・タブレット専門 | 月額1万／出品500円/台／トライアル2回無料 | スマホ月10台を超えたら（トライアルで試す） |
| エコリング the Auction | ブランド市・道具市（カメラ・楽器・家電） | 入会3万＋年2万 | 月商が立ってから |
| Strade Wholesale | スマホ 10〜500台ロット・固定価格 | — | 単品では使えない。ロットが溜まったら |
| 地金買取業者 | 貴金属（地金） | 0円 | 当日相場で即。オークション不使用 |
| 地元の卸・業者買取 | カメラ・楽器・ゲーム・家電 | 0円 | 初期はここに3社相見積もり |

### 4-2. 卸先の見つけ方（諏訪圏起点）
1. **業者オークションの会員規約で「法人・古物商許可証」だけで入れるものから入会**（上の表の 0 円枠）。
2. **地元の卸**は、同業者の求人・ジモティーの業者投稿・リサイクルショップの法人窓口から辿る。電話で「古物商の法人です。仕入れ相談ではなく、こちらから品を卸したい」と言えば通る。
3. 入会審査で **営業実態の写真**（事務所入口の社名表示・名刺）を求められることがある。自宅兼事務所なら**入口に社名プレートを貼ってから撮る**。

### 4-3. 交渉と比較（査定スキルがなくてもできること）
- **比べるのは「値段」ではなく「落札額 − 手数料 − 送料 − 入金までの日数」**。表計算で1品ずつ記録する。
- 地元業者への相見積もりは**同じ写真セットを3社に同時送付**。返答速度と値段を記録し、月1回「先月一番高かった業者」を主契約に寄せる。
- 業者オークションの落札結果はそのまま**翌月の目安額の根拠データ**になる。落札額を品目別に台帳とは別のシートに残す。

## 5. 古物台帳・本人確認の運用（免許を活かす部分）

### 5-1. 本人確認（非対面）
非対面取引の本人確認は法定の方法に限られる。宅配買取で最も一般的な組み合わせ:
1. **本人確認書類の写しを品物に同梱**してもらう
2. **写しに書かれた本人名義の口座**へ振り込む
3. **写しの住所へ転送不要郵便（簡易書留等）で「お預かり証」を送る**ことで住所を確認

> ★ この組み合わせが自分の運用で足りるかは、**着手前に管轄警察署（生活安全課）に電話で確認する**。
> ★ 「ホームページ利用取引」を行うため **URL の届出（変更届）** が必要。LP公開前に提出する。
> ★ 未確認事項: 委託（お預かり販売）でも買取と同じ本人確認義務が受託時に生じる、という前提で運用する。

### 5-2. 古物台帳（法定記載事項をそのまま列にする）
| 列 | 内容 |
|---|---|
| 取引年月日 | 受入日／払出日 |
| 区分 | 受入（お預かり）／払出（オークション落札） |
| 品目・特徴 | ブランド・型番・シリアル・色・傷の特徴 |
| 数量 | 点数 |
| 代価 | 落札額／お客様への振込額 |
| 相手方 | 住所・氏名・職業・年齢（受入は売主、払出はオークション運営会社） |
| 確認方法 | 「本人確認書類の写し＋本人名義口座振込＋転送不要郵便」等、実際に行った方法 |
| 証跡 | 追跡番号・開封動画ファイル名・本人確認書類の保管番号 |

- 台帳は**スプレッドシート1枚**で始める（Web化は運用が回ってから）。
- 本人確認書類の写しは**紙のまま鍵付きで保管**し、台帳には保管番号だけ書く。
- 保存期間は法定期間に従う（3年）。

### 5-3. 免許を「安心」に変換する（LP・LINEで見せる）
- 許可番号・法人名・公安委員会名をLPの目立つ位置に表示（法定の表示義務でもある）。
- 「開封動画を撮って保管」「明細を全件公開」「出品先の種別を明記」の3つを**約束として書く**。
- 盗品防止に協力している旨（本人確認を必ず行う）を明記する。「怪しい人が来ない」効果もある。

| 媒体 | やること | 文面の型 |

## 8. CVR・LTVの工夫（まとめ）

### 初回CVR
- **モニター10件（手数料15%）**: 「欲しい」ではなく「送る」という行動を引き出す最初のオファー。明細と感想の公開が対価。埋まったら通常20%へ戻す（`config.js` の `MONITOR_ENABLED`）。
- **速度**: 目安額は24h以内。「営業時間内は○時まで」と時刻を出す。
- **即金の代替**: 入金予定日を確定日で書く／最低希望額を下回れば無料返送／到着当日に開封動画。
- **安心**: 許可番号・法人名の表示、追跡番号の共有、明細公開の約束、断っても費用ゼロを明記。
- **離脱要因の先回り**: 傷のアップを最初に撮ってもらう（到着後の減額が最大の離脱理由）。

### LTV
- 手数料 20% → 2回目 17% → 紹介で 14% 上限。**下げ幅は「次に送る理由」にだけ使う**。
- 振込完了メッセージが最大の再来店接点。特典・品目チェックリスト・大会告知をここから派生させる。
- 配信は月1回上限。トリガー配信のみ。

### 全国対応の安心感
- 追跡番号をお客様から受け取り、到着・出品・落札・振込の4回、状況を送る。
- コンビニ受け取り（受取人側で配送会社の会員サービスから受取場所を変更する運用）。**送り先住所は届出済み営業所**。
- 出品先の種別（業者オークション／地金業者／卸）を明細に書く。転売先を隠さない。

### 手数料の最適化
- 全部込み 20%（オークション実費を含む）。低額品は「目安額 5,000 円以上」で受付を切る。
- 送料はお客様負担。落札 5 万円以上で 1,000 円上乗せ（CVR用）。
- 買取（即金）レーンは **手元資金 30 万円 or 月間成約 20 件** を超えてから追加する。
